虚拟声卡首次安装说明

程序运行所需的 .NET 与 WinUI 依赖已内置，不需要另行联网下载。

要让主机也延迟播放，首次需要安装一次虚拟声卡：
1. 解压同目录内未经修改的 VBCABLE_Driver_Pack46.zip 到一个文件夹。
2. 右键其中的 VBCABLE_Setup_x64.exe，选择“以管理员身份运行”。
3. 在官方安装器中点击 Install Driver，按它的提示完成安装并重启电脑。
4. 启动宿舍之音。在“同步设置”中选择 CABLE Input 为采集设备，Realtek/实际扬声器为主机输出，勾选“主机也延迟播放”后保存。
5. 点击开始广播；让音乐软件跟随 Windows 默认输出。音乐软件固定声卡时，手动选择 CABLE Input。

程序会尝试在首次启动检测到虚拟声卡时自动选择合适的默认设备。不同电脑的声卡名称可能不同，请确认实际输出选择正确。
Windows“侦听此设备”应关闭，避免额外播放未延迟的声音。
