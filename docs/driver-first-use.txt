虚拟声卡（VB-CABLE）说明

程序运行所需的 .NET 与 WinUI 依赖已内置，不需要另行联网下载。

宿舍之音 0.7.0 起：
1. 安装程序会检测是否已安装 VB-CABLE 虚拟声卡；若尚未安装，将自动请求管理员权限安装虚拟声卡（已安装则自动跳过）。
2. 进入软件后只需选择本机实际输出设备（扬声器或耳机），虚拟声卡由软件自动选择；若检测到未安装虚拟声卡，将无法启动广播并提示安装指引。
3. 卸载宿舍之音时，卸载程序会同时卸载 VB-CABLE 虚拟声卡与软件本体。

如需手动安装或修复驱动：
1. 解压同目录内未经修改的 VBCABLE_Driver_Pack46.zip 到一个文件夹。
2. 右键其中的 VBCABLE_Setup_x64.exe，选择“以管理员身份运行”，点击 Install Driver。
3. 按官方提示重启电脑后再打开宿舍之音。

Windows“侦听此设备”应关闭，避免额外播放未延迟的声音。
