# 界面实现说明

按用户要求安装并读取了 nextlevelbuilder/ui-ux-pro-max-skill 的 UI UX Pro Max。设计检索匹配 Music Streaming 的暗色音乐配色与 Minimalism & Swiss Style；它的营销展示页建议不适用于接收播放器，因此只采用清晰层级、单一主操作、足够对比、原生控件、减少动画和按需展示诊断的规则。

网页保留既有浅绿品牌色，使用系统字体，无在线字体、图标 CDN 或新增前端依赖。主机为 WinUI 3，随后按用户要求改为跟随 Windows 浅色/深色及强调色，用系统 Acrylic 背景与原生实色回退。iOS 图标仅作为头部资源，不增加页面正文。

音量操作采用后台端点缓存与最新值合并，避免在界面线程运行音频设备枚举。窗口移动交给系统标题栏拖动机制；半透明交给系统合成，不用网页或定时器模拟背景模糊。
